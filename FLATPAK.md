# Flatpak Packaging - Developer Guide

**Distribution:** [COSMIC Flatpak](https://github.com/pop-os/cosmic-flatpak) (primary - COSMIC Desktop exclusive applet) or [Flathub](https://flathub.org) (alternative)

**Note:** This is a COSMIC Desktop applet and will NOT function as a panel applet in KDE, GNOME, or other desktop environments. It requires COSMIC Desktop's panel applet framework.

## Quick Start

```bash
# Prerequisites
sudo apt install flatpak flatpak-builder just
flatpak remote-add --if-not-exists --user cosmic https://apt.pop-os.org/cosmic/cosmic.flatpakrepo

# Generate cargo sources (required for offline builds)
just flatpak-sources                                # Auto-installs flatpak-cargo-generator if needed

# Build and test
flatpak-builder --user --install --force-clean build-dir com.slagmine.astra.json
flatpak run com.slagmine.astra
RUST_LOG=debug flatpak run com.slagmine.astra      # Debug mode
```

## Cargo Sources Generation

```bash
just flatpak-sources                            # Preferred: auto-installs flatpak-cargo-generator
# OR manually:
cargo install flatpak-cargo-generator
flatpak-cargo-generator Cargo.lock -o cargo-sources.json

# IMPORTANT: Regenerate when Cargo.lock changes (excluded from git)
```

## Build & Test

```bash
# Local build
flatpak-builder --user --install --force-clean build-dir com.slagmine.astra.json
flatpak run com.slagmine.astra

# Testing
flatpak run --env=RUST_LOG=debug com.slagmine.astra        # Debug logs
flatpak info --show-permissions com.slagmine.astra         # Check permissions
flatpak run --command=sh com.slagmine.astra                # Inspect filesystem

# COSMIC Flatpak repo (alternative to Flathub)
git clone https://github.com/pop-os/cosmic-flatpak
cd cosmic-flatpak
mkdir -p app/com.slagmine.astra
cp /path/to/com.slagmine.astra.json app/com.slagmine.astra/
cp /path/to/cargo-sources.json app/com.slagmine.astra/
just build com.slagmine.astra
```

## Validation & Submission

```bash
# Validate before submission
appstreamcli validate resources/com.slagmine.astra.metainfo.xml  # AppStream (production-ready)
desktop-file-validate resources/com.slagmine.astra.desktop       # Desktop file (production-ready)
flatpak-builder --show-manifest com.slagmine.astra.json          # Manifest validation

# Pre-submission checklist
# [x] Manifest, AppStream, desktop file validated
# [x] Icon (PNG 256x256), 6 screenshots, 5 languages (en,de,es,gd,ja)
# [x] GPL-3.0-or-later license
# [ ] cargo-sources.json generated (just flatpak-sources)
# [ ] Clean build test passed
# [ ] Runtime test passed
```

**AppStream** (`resources/com.slagmine.astra.metainfo.xml`): Complete description, 6 screenshots, release info, URLs, categories (Utility/Network), keywords (5 languages), OARS rating

**Desktop file** (`resources/com.slagmine.astra.desktop`): Localized names/comments (5 languages), COSMIC config (X-CosmicApplet, X-CosmicHoverPopup), Flatpak migration marker

## Troubleshooting

```bash
# Build failures
flatpak-cargo-generator Cargo.lock -o cargo-sources.json  # Regenerate if offline fetch fails

# Runtime issues
flatpak override --user --talk-name=org.freedesktop.secrets com.slagmine.astra  # API key storage
flatpak override --user --share=network com.slagmine.astra                      # Network access
flatpak run --command=sh com.slagmine.astra                                     # Check desktop file
ls /app/share/applications/
```

## Submission

**COSMIC Flatpak (primary):**
1. Fork [pop-os/cosmic-flatpak](https://github.com/pop-os/cosmic-flatpak)
2. Create `app/com.slagmine.astra/`, add manifest + cargo-sources.json
3. Test: `just build com.slagmine.astra`
4. PR with manifest, cargo-sources.json, description, screenshots
5. COSMIC Flatpak hosts "applets and other flatpaks for COSMIC that are not suitable for upload to Flathub"

**Flathub (alternative):** Follow [submission guidelines](https://docs.flathub.org/docs/for-app-authors/submission) - Note that this applet requires COSMIC Desktop to function as a panel applet
